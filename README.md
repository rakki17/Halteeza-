# Halteeza Tech & Solutions — Website

A clean, responsive, GitHub-ready static website for **Halteeza Tech & Solutions**.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts (DM Sans + Manrope)
- No build step required

## Run locally
Open `index.html` directly in a browser, or use a simple local server:

```bash
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Deploy
This project can be deployed directly to:
- GitHub Pages
- Netlify
- Vercel
- Any standard web hosting

## Before production
1. Replace portfolio placeholders with verified projects.
2. Add approved client logos/screenshots only where permission exists.
3. Confirm team details and contact information.
4. Add the final company logo if available.
5. Connect a real enquiry form/backend if required.
6. Review WhatsApp messaging/API compliance and customer opt-in requirements.
